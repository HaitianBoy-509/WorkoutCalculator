--- Workout Calculator App ---

Workout Calculator is a .NET MAUI fitness application designed to help users plan and track gym sessions with a clean modern UI.

The app combines:

Workout load calculation
Smart training recommendations
Session timer
Exercise visualization
Workout history tracking
Features
Weight Calculator

--- Calculate the total training load based on user input ---

Inputs:
Total weight
Training goal
Smart Coach Mode

The app generates training guidance based on the selected objective:
Force
Heavy compound recommendations
Strength-focused progression
Hypertrophy
Muscle growth protocols
Volume optimization
Endurance
High-repetition training guidance
Conditioning recommendations
Session Timer

Built-in workout timer with:
Start
Pause
Stop / Reset

--- Allows users to track full workout duration --- 

Users can:

Review previous workouts
Track progression
Delete old sessions


--- Learning Objectives ---

This project demonstrates:
Event-driven programming
UI design with XAML
State management
Timer implementation
Data persistence
Dynamic content rendering
